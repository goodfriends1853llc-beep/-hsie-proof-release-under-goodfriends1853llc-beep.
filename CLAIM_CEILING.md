# HSIE Proof Release v0.1.0 — Claim Ceiling

## Supported

This release supports the statement that:

1. 560 source-row identities are accounted for through preserved lineage.
2. Phase 2 resolves to 128 DEDUP engineering obligations.
3. Phase 3 contains 136 normalized requirements across 17 irreducible fronts.
4. Phase 4 assigns all 136 requirements executable work-order paths.
5. Phase 5 provides a local reference implementation spanning all 17 fronts, with a preserved initial failed suite and corrected 109/109 internal test pass, plus PT-001 11/11 pass.
6. Phase 6 installs the reference implementation on one explicitly named bounded local sandbox target and verifies 109/109 tests plus PT-001 11/11; a clean internal isolated reproduction repeats the result.
7. Current requirement-level assurance state is preserved without silently promoting partial/external/validation-gated requirements.

## Not supported

This release does NOT support claims of:

- recovered original TB-SUB-001 bytes;
- recovered original canonical 560-row Candidate Anatomy raw-text source artifact;
- verified/canonical HSA-CON-001 authority;
- independent reproduction by an independent actor;
- external peer review;
- field validation;
- production deployment;
- live regulated-source access;
- real external financial settlement;
- real physical-world actuation/effect validation;
- universal fitness;
- standards-body certification;
- public release authorization.

## Core distinctions

Architecture ≠ implementation.  
Implementation ≠ internal verification.  
Internal verification ≠ independent reproduction.  
Repeatability ≠ independence.  
Named local target ≠ production.  
Protocol ≠ performed assurance.  
Sandbox effect ≠ physical-world effect.  
Local financial control ≠ real settlement.  
Reference to foundation ≠ custody of foundation bytes.
