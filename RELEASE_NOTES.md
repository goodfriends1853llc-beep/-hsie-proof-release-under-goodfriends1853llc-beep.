# HSIE Proof Release v0.1.0 — Publication Notes

This is the first evidence-bounded publication candidate for the HSIE ANAT proof chain.

The release is intentionally conservative. It publishes what is supported by preserved artifacts and hashes and explicitly leaves unresolved authority, custody, external, independent, field, production, and public-authorization gates visible.
